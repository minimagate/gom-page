## What this site collects

This is a static research archive. It does not contain analytics, advertising, accounts, forms, comments, or sign-up flows, and the repository contains no code that collects personal information for those purposes.

This repository contains no application backend or code for request logging. The service that hosts these static files may still process ordinary technical data needed to deliver and secure the site. That hosting layer is outside this archive's control; the archive does not use such data for tracking or advertising.

## Third-party resources

The site's styles and fonts are served from this archive, including the local copy of Geist Mono. The base template loads MathJax from jsDelivr so that pages containing equations can render them in the browser. That load is a request to a separate provider and is subject to that provider's practices, not this policy.

The interactive charts are generated Plotly HTML files published with the archive. Their Plotly library is included in the chart files, so the chart itself is not a form, account, or analytics feature.

Links to GitHub, model pages, and the author's website take you to separate services with their own privacy practices. This policy does not cover those services.

## Cookies

This site does not set cookies as part of its own pages or features. See the [cookie policy](/cookies/) for more detail.

## Changes to this policy

This policy may be updated as the archive or its resources evolve. Changes will be reflected on this page.

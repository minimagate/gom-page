## No cookies, no tracking

The archive's own pages do not set first-party cookies, analytics cookies, or advertising cookies. There is no cookie banner because the current site has no cookie-based feature or consent flow.

## Local and external resources

The site uses local styles and a local copy of Geist Mono. Pages with mathematical notation load MathJax from jsDelivr, but the archive does not use that resource to set cookies or track visitors.

Interactive Plotly charts are published as generated HTML files with their chart library included. They do not add a sign-in, form, analytics, or advertising feature to the archive.

See the [privacy policy](/privacy/) for more about technical requests and third-party resources.

## If that changes

If the archive starts using cookies or similar technologies, this page and the [privacy policy](/privacy/) will be updated to describe what is used and why.
